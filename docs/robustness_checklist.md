# Robustness Checklist

## Identification Checks

- [ ] Pre-trend or placebo timing check, if applicable
- [ ] Alternative control group or comparison set
- [ ] Alternative sample restriction
- [ ] Alternative outcome construction
- [ ] Alternative fixed effects
- [ ] Alternative clustering or standard error approach

## Measurement Checks

- [ ] Source-level variable audit
- [ ] Missingness audit
- [ ] Outlier audit
- [ ] Unit consistency check
- [ ] Timing alignment check

## Specification Discipline

- [ ] Preferred specification was defined before looking for significance
- [ ] Robustness checks are reported as robustness checks, not cherry-picked replacements
- [ ] Null or ambiguous results are preserved

## Claim Discipline

- [ ] Descriptive findings are not described as causal
- [ ] Historical estimates are not described as forecasts
- [ ] Policy translation does not exceed sample and period
