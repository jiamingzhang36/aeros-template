# CURRENT_STATE

current_goal: State the current project objective in one sentence.
latest_substantive_artifact: Name the newest real data, source, full-text extraction, result, paper edit, or approved artifact.
current_blocker: State the current blocker, or `None`.
next_command: Put the next command Codex should run, or the exact human decision needed.
does_not_prove: State what the latest PASS/route/output does not prove.
last_validation: Record the last validation command and result with date.
