# Resources

This file is a curated pointer list for tools and standards that AEROS can borrow from without trying to replace.

## Reproducible Empirical Research

- Reproducible project templates: project structure, automated pipelines, and output rebuilds.
- Research transparency standards: master scripts, code review, data provenance, and reproducibility checks.
- Social Science Data Editors replication README template: replication package documentation standard.

## AI and Agent Workflows

- AGENTS.md: project instructions for coding agents.
- Agent harness patterns: instructions, permissions, routing, validation checks, logs, critic review, and run reports.
- GitHub Agentic Workflows: read-only defaults, sandboxing, allow lists, and human approval gates.
- Coding-agent issue workflows: issue-based task specs, isolated branches or worktrees, checks, diffs, and review.

## Research Assistant and Tool Indexes

- Research assistant guides: coding, data work, reproducibility, causal inference, and documentation practices.
- AI-for-research tool indexes: literature tools, coding tools, data extraction, analysis, and reporting resources.
- Economics skill catalogs: ideation, literature review, theory, data, econometrics, writing, visualization, communication, and engineering skills that can be mapped into AEROS through `harness/skill_map_core.yml` (core) and `harness/skill_map_reference.md` (reference).
- Economics writing skills: section formulas, writing audits, referee simulation, and paper revision workflows that must remain bounded by `evidence/claim_registry.md` and `docs/language_constraints.md`.
- Academic research skills: paper review, code review, computational reproducibility, novelty gates, source inspection, claim verification, and pre-submission review. Use these as audit or support layers, not as replacements for AEROS evidence gates.

## AEROS Rule

Use these resources as references. Do not import complexity before a real project needs it.
