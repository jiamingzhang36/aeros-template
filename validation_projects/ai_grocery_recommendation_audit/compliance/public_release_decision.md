# Public Release Decision

release_status: internal-only

## Decision

The current project is internal-only. Public release is not approved.

## Rationale

The project is a validation run of the AEROS workflow. It contains synthetic personas, generated AI outputs, mock-provider test outputs, audit reports, and replication scaffolding. Provider terms, generated-output redistribution status, data README placeholders, and public package instructions are not yet fully resolved.

## Allowed Uses

- Internal AEROS validation
- Workflow debugging
- Human review of gate discipline
- Non-public method development

## Not Approved

- Public replication package release
- Submission as final empirical paper
- Claim upgrade to supported status
- Deployed-system conclusions
- Public benchmark claims about provider/model performance

## Human Approval Requirement

A human owner must explicitly approve any future public release after provider terms, data licenses, privacy/IRB status, and replication package readiness are reviewed.

Approver: not approved for public release
