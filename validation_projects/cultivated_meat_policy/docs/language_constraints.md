# Language Constraints

## Allowed Language

Use language consistent with the design and evidence.

Descriptive:

- "is associated with"
- "is higher / lower in"
- "differs across"

Causal, only if supported:

- "causes"
- "leads to"
- "reduces"
- "increases"

Policy translation, only if supported:

- "suggests"
- "is consistent with"
- "within this setting"

## Restricted Language

Do not use unless explicitly supported in `claim_registry.md`:

- "proves"
- "shows that policy will"
- "predicts future effects"
- "applies to all households / firms / states / countries"
- "demonstrates mechanism" when mechanism evidence is indirect
